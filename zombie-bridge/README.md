# 屍潮斷橋

《Last Z: Survival Shooter》廣告玩法的網頁平替版。單一 HTML 檔，用 Three.js（從 cdnjs 載入）畫 3D，不需要建置。

## 玩法

- 小隊會自己往前跑、自動開火。按住畫面左右拖曳（電腦可用 ← → 或 A / D）移動。
- **數字門**：子彈打在門上會讓數字 +1。從門下穿過時，小隊人數會加上（或乘上）門上的數字。紅色負數會扣人。
- **全息機甲**：射擊底座前的電池，充滿 100% 就會召喚機甲加入，並給小隊 4 秒護盾。
- **地上的槍**：走過去撿起來升級武器（手槍 → 步槍 → 散彈槍 → 加特林）。
- 走到橋尾會出現**巨屍**，打倒它就過關。殭屍碰到隊員會同歸於盡，隊員全滅就失敗。
- 每一關的地圖固定（同一關重玩一樣），關卡越後面殭屍越多、越硬。

## 本機執行

直接用瀏覽器打開 `index.html`，或在這個資料夾起一個靜態伺服器：

```bash
npx serve zombie-bridge
```

最佳紀錄存在瀏覽器的 localStorage。
