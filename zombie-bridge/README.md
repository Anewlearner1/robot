# 屍潮斷橋

《Last Z: Survival Shooter》廣告玩法的網頁平替版。單一 HTML 檔（`index.html`），用 Three.js r128 畫 3D，從 cdnjs 載入，不需要建置。

## 玩法

### 操作

- 左右拖曳畫面移動小隊。電腦可用 ← → 或 A / D。
- 小隊會自己往前跑、自動開火，玩家只負責左右移動，並選擇要穿過哪一邊的門。
- 暫停：右上角暫停鈕、Esc 或 P。切到其他分頁時會自動暫停。
- 右上角「音」可以切換音效。

### 小隊與數字門

- 小隊人數上限 100（`TUNE.maxSquad`）。
- 數字門成對出現，橋的左右各一扇。小隊的重心在哪一側，就穿哪一側的門。重心正好在中線上時，拿到的是較差的那扇。
- 門的種類：
  - **藍色正數（+n）**：小隊加 n 人。
  - **紅色負數（-n）**：小隊扣 n 人。扣到 0 就失敗。
  - **×2 門**：小隊乘以 2（四捨五入）。偶爾出現，不能射。
  - **數字門可以射**：子彈的傷害累積到門上的需要量就 +1。需要量 = (2 + 關數 + 12 × min(小隊人數, 40)) × 係數，人數超過 40 後不再增加（`TUNE.gateSquadRef`）。開場的第一扇紅門只需要 35% 的量。
  - **金色射速門**：射速 +20%，只在本關有效。
  - **紫色槍等級門**：目前的槍升 1 級。已經滿級時改為 +3 人。
  - **問號門（?）**：一開始看不到內容。射中累積 20 點傷害或穿過去就會揭曉，多數是正面的。
- 岔路上每一側只有一扇門，小隊走哪一邊就吃哪一邊的門。

### 武器與等級

- 每關開場拿手槍（Lv1），開場還有一個中間車道的步槍箱。
- 槍箱在三條車道上（x = -2.6、0、2.6）。小隊的重心要站在箱子所在的車道才撿得到。每一排槍箱至少留一條空車道，可以選擇不撿。
- 一排的兩個箱子是二選一，撿到其中一個另一個就消失。
- 每個槍箱自帶 8 名新兵，再加上「援軍」強化的人數。
- 撿到同一把槍會升級，傷害每級乘上該槍的 `lvMul`，最高 Lv3。已經滿級再撿，只拿到新兵。
- 撿到不同的槍會換槍，回到 Lv1。
- 第 1–3 關的槍箱配置固定。第 4 關以後每關隨機，但七把槍每關都會出現。

### 機甲與電池

- 每關開場有一座機甲底座，上面的電池要用子彈射到滿。電池需要的傷害 = 6 + 6 × 關數（第 1 關 12，第 5 關 36）。
- 小隊走過底座 1.5 單位以上還沒射滿，就錯過了，本關沒有機甲。
- 射滿後機甲加入，會跟在小隊旁邊。小隊同時獲得 4 秒護盾（每級「護盾」強化 +1 秒）。
- 機甲每 0.62 秒發射兩發砲彈，傷害 = 1.4 + 0.6 × 關數。砲彈在命中處爆炸，範圍約 1.8 單位，範圍內的殭屍也會受傷（約為本體的 40%）。
- 護盾開著時，殭屍碰到小隊不會扣人。護盾關掉時，殭屍碰到一名隊員就死一人。

### 殭屍與地形

- 殭屍種類：`wall` 牆、`blob` 團、`line` 線、`swarm` 群（數量多、血薄）、`runners` 奔跑者（數量少、跑得快）、`brutes` 大型（血厚，掉道具機率最高）。
- 油桶：5 點血量。被射爆後，半徑 3.2 內的殭屍各受 4 點傷害（最多 20 隻）。巨屍在範圍內也會受傷。
- 爆炸殭屍：死亡時爆炸（半徑 1.8，傷害 2，每次最多 6 隻），會連鎖引爆附近的爆炸殭屍，連鎖最多 6 層。
- 盾牌殭屍：正面直線飛來的一般子彈會被擋，擋 4 下後盾破。穿透、範圍、火焰槍的子彈和從側面射來的子彈會穿過。
- 道具（掉落後會被小隊吸過來）：
  - **狂熱**：射速 ×1.4，持續 4 秒。
  - **分裂彈**：每發多 2 顆子彈，多出來的子彈傷害為 30%，持續 5 秒。
- 連殺：兩次擊殺間隔不超過 1.2 秒就算連殺。連殺達到 25 / 50 / 100 / 200 會給金幣，連殺到 100 與 200 時另有 2 秒狂熱。

### 巨屍

- 小隊走到橋尾時，巨屍在前方 26 單位處出現，畫面上方出現血條。
- 巨屍血量 = 220 × 關數 + 11.5 秒 × 小隊的每秒傷害。這裡的每秒傷害用小隊人數與目前槍的基礎數值估算，不計強化與加成。各槍的 `bossEff` 只作為算血量時的權重，不改變子彈對巨屍的傷害。
- 巨屍每 3.4 秒召喚一批小殭屍，每批 6 + 2 × 關數 隻。
- 巨屍靠近小隊時，每 0.6 秒結算一次：護盾沒開就死 2 人，然後巨屍被彈回 4.5 單位。
- 約一半的隊員會瞄準巨屍，其餘的打小殭屍。
- 巨屍倒下後，小隊不會再死人。1.6 秒後判定過關。

## 武器

數值取自 `WEAPONS`。射速是每名隊員每秒的發數（步槍是三連發點射，平均射速仍是表中的數字）；傷害是每發的基礎傷害；穿透是一發子彈額外能穿過的殭屍數；範圍是爆炸半徑（0 為沒有爆炸）；飛行方式是 `traj`。

| 名稱 | 說明 | 飛行方式（`traj`） | 射速 | 傷害 | 穿透 | 範圍 |
| --- | --- | --- | --- | --- | --- | --- |
| 手槍 | 基本配槍 | `straight` | 8.9 | 2.5 | 0 | 0 |
| 步槍 | 射速快、射程長 | `burst` | 11.4 | 1 | 1 | 0 |
| 散彈槍 | 近距離一次轟一片 | `fan` | 7.8 | 1 | 0 | 0 |
| 加特林 | 火力全開的彈幕 | `spray` | 20.7 | 1 | 0 | 0 |
| 狙擊槍 | 一發貫穿整排 | `beam` | 1.7 | 3.5 | 5 | 0 |
| 火焰槍 | 燒穿整群，射程短 | `stream` | 6.4 | 1.0 | 2 | 0 |
| 火箭筒 | 爆炸範圍傷害 | `lob` | 1.4 | 8 | 0 | 1.7 |

飛行方式：

- `straight`：直線飛行。
- `burst`：三連發點射，三發之間隔很短，接著停頓，平均射速不變。
- `fan`：扇形散開，子彈飛越遠越慢，速度降到一定程度就消失，射程比表中的 range 短約 25%。
- `spray`：左右蛇行，每名隊員的相位不同，所以不會整排同步擺動。
- `beam`：幾乎瞬間的直線光束，不會飛行，貫穿整排。
- `stream`：減速，同時往上飄，並左右飄移。
- `lob`：拋物線飛向目標，中途微追蹤目標附近的殭屍，落地爆炸；飛得高時會越過前排，只有落下時才會碰到殭屍。

其他：

- 每次射擊的子彈數：散彈槍 5 顆，火焰槍 2 顆，其餘 1 顆。
- 升級：每級傷害乘上 `lvMul`，手槍 ×1.6，其他槍 ×1.3，最高 Lv3。

## 關卡路線

每一關的地圖固定，同一關每次重玩都一樣。殭屍群每次釋放的人數會有 ±25% 的浮動。橋長 = 170 + 25 × 關數 + 路線加長。

| 關 | 名稱 | 主題（`theme`） | 橋長 | 路線 |
| --- | --- | --- | --- | --- |
| 1 | 新手橋 | `dawn` | 195 | 直橋。武器箱、牆、數字門、線、團、大型、群、奔跑者依固定順序重複。 |
| 2 | 雙岔路 | `sunset` | 265 | 直路，接兩段岔路（左：數字門與團；右：油桶與大型。第二段左：線與數字門；右：油桶與團），最後重複牆、數字門、群、大型。 |
| 3 | 殘橋 | `haze` | 270 | 直路，接兩段窄橋（半寬 1.5：團、線、油桶；半寬 1.2：奔跑者、大型），最後重複。 |
| 4 | 油桶廊道 | `night` | 270 | 直路，接油桶廊道（油桶夾雜群與團），再接兩側伏擊（牆、團，從兩邊同時來），最後重複。 |
| 5 | 終局之橋 | `storm` | 325 | 每種路段各一次：直路、岔路（左：數字門與線；右：油桶與大型）、窄橋（半寬 1.4）、油桶廊道、兩側伏擊（群），最後重複。 |

- 窄橋：路面縮窄，小隊與殭屍都被限制在窄路內。
- 岔路：中間有隔欄，小隊進入後只能走一側。
- 兩側伏擊：同一群殭屍分成左右兩半，從兩側同時來，釋放得較晚。
- 第 6 關起由種子生成路線，同一關每次都一樣，名稱取自固定名單。

## 強化商店

數值取自 `UPGRADES`。價格 = 基礎價 × 倍率^目前等級（四捨五入）。下表的價格依序是從 Lv0 升到 Lv1、Lv1 到 Lv2……Lv4 到 Lv5。可以在選單和結算畫面打開商店。

| 名稱 | 效果（每級） | 最高等級 | 各級價格 |
| --- | --- | --- | --- |
| 火力 | 全隊傷害 +10% | 5 | 220 / 440 / 880 / 1760 / 3520 |
| 射速 | 全隊射速 +8% | 5 | 220 / 440 / 880 / 1760 / 3520 |
| 援軍 | 每個槍箱多 +1 名隊員 | 5 | 200 / 380 / 722 / 1372 / 2606 |
| 護盾 | 機甲護盾 +1 秒 | 5 | 120 / 216 / 389 / 700 / 1260 |
| 幸運 | 金幣 +15%、爆擊率 +3% | 5 | 150 / 285 / 542 / 1029 / 1955 |

爆擊的基礎機率為 8%，爆擊時傷害 ×2。

## 存檔與破關保留隊員

- 存檔存在瀏覽器的 localStorage，鍵名 `zombie-bridge-save`（版本 1）。清除瀏覽器資料或換裝置，存檔就不見了。
- 存檔內容：金幣、各項強化等級、已解鎖的最高關、每一關的起始兵力（`entry`）與最佳星數（`stars`）。
- **過關**（巨屍倒下）：
  - 剩下的人數存為下一關的起始兵力。若下一關已有更大的紀錄，保留較大者，上限 100。
  - 解鎖下一關。
  - 星數只會升不會降：1 顆 = 過關；剩下的人數 ≥ 起始兵力 → 2 顆；剩下的人數 ≥ 3 星門檻 → 3 顆。3 星門檻 = min(95, max(⌈起始兵力 × 1.5⌉, 起始兵力 + 10))，也就是不超過上限的 95%。
- **輸掉**：下一關的起始兵力不變，只有本關金幣的一半會入帳。
- **重玩或從選單出發**：用這一關目前存的起始兵力。第 1 關起始兵力固定為 ×1。
- **選關**：選單的左右箭頭可以選已解鎖的關卡，最多到最佳紀錄那一關。
- 金幣來源：
  - 擊殺給基礎金幣：普通 0.035、群 0.025、爆炸殭屍與盾牌殭屍 0.12、大型 1.2、巨屍 25。每一項再乘上 (1 + 0.2 × (關數 − 1)) 與幸運加成。
  - 連殺與人數里程碑（10 / 25 / 50 人）另有金幣。
  - 過關的星數獎勵：每顆星 40 × (1 + 0.2 × (關數 − 1))。
- 舊存檔只有 `zombie-bridge-best` 時，第 2 關以後的起始兵力預設為 25。

## 本機執行

直接用瀏覽器打開 `index.html`，或在這個資料夾起一個靜態伺服器：

```bash
npx serve zombie-bridge
```

three.js 從 cdnjs 載入，需要能連上網路。

## 測試

測試腳本都用 Node 和 Playwright 驅動 headless Chromium，載入 `index.html` 並透過 `window.__zb` 推進模擬。Playwright 來自 `/opt/node-tools/node_modules/playwright`。three.js 預設讀取 scratchpad 內的本機檔案，可用環境變數 `THREE_JS=/path/to/three.min.js` 改掉；`ZB_HTML=/path/to/index.html` 可以測別份 HTML。

- **checks.mjs**：邏輯回歸檢查（固定步長、暫停、關卡重置、存檔、升級、各種殭屍與門的規則等）。失敗或頁面有 console error 時結束碼為 1。
  ```bash
  node zombie-bridge/tests/checks.mjs
  ```
- **playtest.mjs**：機器人平衡測試，可以跑單關或整段戰役。
  ```bash
  node zombie-bridge/tests/playtest.mjs
  node zombie-bridge/tests/playtest.mjs --n 200 --stages 2
  node zombie-bridge/tests/playtest.mjs --campaign --n 200 --seed 1 --upgrades
  ```
- **perf.mjs**：量 `step()` 的耗時。`CPU_THROTTLE=4` 可以模擬 4 倍慢的手機 CPU。
  ```bash
  node zombie-bridge/tests/perf.mjs
  CPU_THROTTLE=4 node zombie-bridge/tests/perf.mjs
  ```
- **shots.mjs**：截圖，供視覺檢查用。依序拍選單、第 1–5 關的中段、第 1 關的巨屍戰、勝利結算、強化畫面。預設存到 `zombie-bridge/tests/shots-out/`（已列入 `tests/.gitignore`）。
  ```bash
  node zombie-bridge/tests/shots.mjs
  node zombie-bridge/tests/shots.mjs --out zombie-bridge/tests/my-shots --w 390 --h 844
  ```

各腳本的完整旗標見 `zombie-bridge/tests/README.md`。另有 `arena.mjs`（武器競技場，固定小隊對六種遭遇戰）也在同一資料夾。
