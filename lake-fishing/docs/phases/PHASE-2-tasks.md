# 湖畔慢釣｜PHASE-2 開發進度與任務文件

- 文件版本：1.0
- 對應產品 PRD：湖畔慢釣 AI 開發 PRD v1.0（`docs/PRD.md`）
- 階段：PHASE-2 — 核心遊戲邏輯
- 本階段原則：只完成核心遊戲邏輯，不提前製作完整 UI、小遊戲或 PHASE-3 以後功能

> 本文件為使用者提供的任務文件原文（任務與驗收清單）。實際進度與結果記錄在 `PHASE-2-report.md`。

## 1. PHASE-2 目標
建立可由 UI 呼叫、可獨立測試的核心遊戲服務：釣魚機率計算與隨機抽取、捕獲結算、金幣經濟與出售、圖鑑紀錄與稀有度解鎖、裝備升級、傳說魚保底、核心服務單元測試。沿用 PHASE-1 的型別、魚類資料、裝備資料與遊戲設定；若 PHASE-1 未完成，先盤點缺項。

## 2. 開始前檢查
- 閱讀主 PRD 與本文件；檢查專案結構與 package scripts。
- 確認 PHASE-1 的型別、25 種魚資料、裝備設定與資料驗證存在。
- 確認測試框架；執行既有測試記錄基準；檢查 Git 狀態；不覆蓋既有可用程式碼。
- 記錄：測試命令／基準結果／建置命令／建置結果／已知問題。

## 3. 建議服務模組
fishingService（稀有度權重、抽魚、捕獲結算）、economyService（出售、金幣、升級成本檢查）、encyclopediaService（首次發現、進度、解鎖）、equipmentService（裝備效果、升級、間隔）、pityService 或等效純函式、types/game.ts、tests。保底可放在 fishingService，避免過度拆檔。

## 4. 功能任務清單

### PH2-01 稀有度解鎖與機率正規化
- 依已發現不同魚種 ID 計算進度；0/5/10/15/20 解鎖普通/少見/稀有/史詩/傳說。
- 未解鎖權重為 0；已解鎖正規化為 1 或 100%；裝備與保底調整後再正規化。
- 處理無有效權重、非有限數值、負權重等異常；隨機函式可注入。
- 驗收：基礎權重 60/25/11/3.5/0.5；未解鎖不會被抽到；各門檻前後一個數量的測試；正規化總和容許誤差（如 1e-9）；測試不依賴真實隨機。

### PH2-02 釣魚與捕獲結算
- 先抽稀有度再抽魚種；只從靜態資料選；每次捕獲更新總捕獲數；首次捕獲才新增 discoveredFishIds。
- 普通／少見自動出售加金幣；稀有以上進魚包或待處理。
- 回傳足夠資訊供 UI，但不混入 UI 狀態；不可直接修改輸入狀態。
- 驗收：重複魚不增加不同魚種數；自動出售金額正確；稀有以上不被誤賣；每次捕獲只結算一次；非法魚種資料或空魚池有清楚可測的錯誤處理。

### PH2-03 金幣經濟與出售
- 單筆出售；批次出售並驗證數量；數量為正整數且不超過持有量。
- 金幣增加與魚數量減少在同一次結算完成；更新 totalFishSold、totalCoinsEarned。
- 不移除圖鑑；金幣不為負；同一筆待處理不可重複出售。
- 驗收：出售 1 隻與多隻金額正確；0、負數、小數、超過持有量被拒；成功／失敗時金幣與魚數一致；出售後圖鑑不變。

### PH2-04 裝備效果與升級
- 釣竿公式 `Math.max(30, Math.round(90 * (1 - 0.08 * (rodLevel - 1))))`，最低 30 秒。
- 釣線效果經集中設定套用於稀有度權重；魚餌效果依設定套用到指定魚種或魚群；倍率不得多處硬編碼。
- 升級前檢查金幣、等級、成本；不足時不變；成功扣款只升一級；Lv.6 不可升。
- 升級成本：釣竿 100/160/260/410/660；釣線 150/240/380/610/980；魚餌 200/320/510/820/1310。
- 未定案參數（釣線倍率、魚餌目標魚群、魚餌倍率）使用集中可調參數，報告中標記「暫定」，不可描述為已確認產品決策。

### PH2-05 傳說魚保底
- 僅在傳說解鎖後生效；0–49 為 0.5%、50–99 為 0.75%、100–149 為 1.0%、150–199 為 1.5%、200+ 為 2.0%。
- 提高後重新分配其他已解鎖稀有度權重；抽到傳說歸零；其他魚依規則增加；未解鎖時不增不減；計數可被存檔保存。
- 驗收：測 49、50、99、100、149、150、199、200；傳說後歸零；更換裝備不重設；調整後總和 100%。

## 5. 核心資料流
GameSave → 讀裝備與圖鑑進度 → 判斷已解鎖稀有度 → 套用裝備權重與保底 → 正規化 → 抽稀有度 → 抽魚種 → 捕獲結算（普通／少見自動出售；稀有以上進魚包／待處理）→ 更新圖鑑、統計、保底 → 回傳新狀態與捕獲摘要。

## 6. 測試清單
- 稀有度與圖鑑：新遊戲只有普通；第 5/10/15/20 種解鎖；重複魚不增加；出售不影響圖鑑；各解鎖階段正規化正確。
- 捕獲與出售：固定 random() 測每個稀有度區間；固定 random() 測稀有度內魚種選擇；普通／少見自動出售；稀有以上保留；非法出售數量被拒；不產生負金幣或負魚數。
- 裝備：金幣不足；剛好足夠；Lv.6 滿級；釣竿不低於 30 秒；釣線、魚餌效果由設定集中控制。
- 保底：49/50、99/100、149/150、199/200；傳說後重置；未解鎖時不動；調整後總和正確。
