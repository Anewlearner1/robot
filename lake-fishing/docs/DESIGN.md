# 湖畔慢釣 — 設計規格（Phase 2）

本文件是所有開發分工的共同依據。修改設計前先更新這裡。

## 已確認的產品決策

| 項目 | 決定 |
|---|---|
| 平台 | 手機直式網頁優先（寬 360–430px），桌機置中顯示同一版面 |
| 玩法 | 完全放置：頁面開著就自動釣魚，不需要點擊 |
| 小遊戲 | 要。稀有以上上鉤時「可選」的收線小遊戲，只給獎勵、不懲罰 |
| 節奏 | 維持現有數值（基礎 90 秒一隻，釣竿 Lv6 為 54 秒） |
| 魚的處理 | 普通／少見自動賣出；稀有以上進背包，玩家手動決定賣或留 |
| 美術 | 像素風，全部用程式繪製（無外部圖檔） |
| 音樂 | 要背景音樂，Web Audio 程式合成的 chiptune，可開關、調音量 |
| 語言 | 繁體中文 |

## 遊戲規則

### 釣魚循環
- 頁面在前景時，每 `getCatchIntervalSeconds(rod)` 秒完成一次釣魚。
- 每次釣魚：依稀有度權重抽稀有度 → 在該稀有度已解鎖的魚中均勻抽一隻。
- 稀有度權重：普通 60、少見 25、稀有 11、史詩 3.5、傳說 0.5（加總 100）。
- 釣線效果（`equipment.ts` line effectValue，0 → 0.10）：把普通魚權重的這個比例（相對於總權重）按目前權重比例分配到少見以上的已解鎖稀有度。規則需寫成純函式並有測試。
- 魚餌效果（bait effectValue，1.00 → 1.25）：賣魚金額乘數（自動賣出與手動賣出都套用，四捨五入取整數）。
- 釣竿效果：間隔乘數，一律從 `equipment.ts` 讀，不可在 service 裡寫死。
- 圖鑑解鎖門檻（已發現種數）：少見 5、稀有 10、史詩 15、傳說 20。

### 傳說保底
- 每次釣到非傳說魚，`pityCounter += 1`；釣到傳說魚歸零。
- 傳說機率依計數提高（沿用 gameConfig 的級距）。增加的機率按比例從其他「已解鎖」稀有度扣除，總和必須維持 100。
- 傳說尚未解鎖時不計保底（計數不增加）。

### 魚的去向
- 普通／少見：立即以 `sellPrice × 魚餌乘數` 換成金幣。
- 稀有／史詩／傳說：進入背包（`inventory`），可單隻賣出或保留。背包不設上限。
- 任何魚第一次釣到即登錄圖鑑（不論賣或留）。

### 收線小遊戲（可選）
- 只在前景、且抽到稀有以上時觸發：畫面跳出「有大魚上鉤！」提示。
- 玩家可以點「收線」進入小遊戲，或不理會；15 秒沒動作就自動收進背包（無獎勵）。
- 小遊戲：張力條。按住拉線、放開放線，讓指示器停在綠色區，進度條滿即成功。約 8–12 秒。參數放在 `gameConfig.minigame`。
- 成功：這隻魚標記為「完美」，賣價 ×1.5。失敗或放棄：照常進背包，沒有懲罰。
- 背景或離線期間不觸發小遊戲。

### 離線收益
- 離開時記錄時間戳；回來時用 `settleOffline` 結算。
- 有效釣魚次數 = floor(min(離線秒數, 4 小時) / 間隔 × 0.5)。
- 每一次都完整模擬抽魚（含保底、解鎖、圖鑑登錄），普通／少見換金幣，稀有以上進背包。
- 回到遊戲時顯示「你不在的時候…」彙總視窗：離開時長、釣到幾隻、獲得金幣、新圖鑑、進背包的稀有魚。
- 系統時間倒退（離線秒數為負）時視為 0。

### 存檔
- localStorage key `lake-fishing-save`；每次釣到魚、每次買賣升級、`visibilitychange` 隱藏時自動存檔。
- 存檔格式升為 `saveVersion: 2`，提供 v1 → v2 遷移。
- 讀檔失敗（JSON 壞掉或驗證不過）時，**不可覆蓋**：把原始字串備份到 `lake-fishing-save-corrupt-<timestamp>`，再開新遊戲並告知玩家。
- `validateSave` 要完整檢查所有欄位（裝備等級範圍、背包、圖鑑 ID 必須是已知魚、數值非負整數等）。
- 設定頁提供匯出／匯入 JSON 與重設遊戲（需二次確認）。

### 資料修正
- 魚 ID `fish_cultrure` 改為 `fish_xenocypris`（imageKey `fish-xenocypris`）。v1 存檔遷移時一併轉換。

## 畫面

底部分頁列（像素風按鈕）：**湖畔 / 背包 / 升級 / 圖鑑 / 設定**

- **湖畔（主畫面）**：像素湖景 canvas（天空依現實時間切換清晨／白天／黃昏／夜晚、遠山、水面波紋、碼頭、釣魚人、浮標上下晃動、偶爾的水花／鳥）。上方顯示金幣；下方顯示「下一隻倒數」進度條，以及最近釣到的 5 筆紀錄。
- **背包**：稀有以上的魚列表（像素魚圖示、名稱、稀有度色、完美標記、賣價），單隻賣出、一鍵全賣（需確認）。
- **升級**：釣竿／釣線／魚餌，顯示目前與下一級效果、價格；金幣不足時按鈕停用。
- **圖鑑**：25 格，未發現顯示剪影「？？？」；已發現顯示像素圖、名稱、稀有度、介紹、累計捕獲數。上方顯示收集進度。
- **設定**：背景音樂開關、音量、匯出／匯入存檔、重設遊戲、版本資訊。

稀有度顏色：普通 灰白、少見 綠、稀有 藍、史詩 紫、傳說 金。

## 技術約定

- 專案位於 repo 的 `lake-fishing/`，獨立的 Vite + React 19 + TypeScript + Vitest 專案。
- 遊戲邏輯一律是 `src/services/` 裡的純函式（可注入亂數 `rng: () => number` 與時間 `now: number`），並有單元測試。React 只負責狀態與畫面。
- 像素美術放在 `src/art/`，音訊放在 `src/audio/`，彼此不互相依賴，也不依賴 React。
- 不使用外部圖片、字型或音檔；不需要網路。
- canvas 一律 `imageSmoothingEnabled = false`，依 devicePixelRatio 整數倍放大。
- 音樂必須在使用者第一次點擊後才開始（行動瀏覽器自動播放限制）；分頁隱藏時暫停。
