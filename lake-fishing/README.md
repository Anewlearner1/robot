# 湖畔慢釣｜MVP 第一階段骨架

此專案是產品需求規格的第一階段工程骨架，尚不是完整遊戲。

## 需求

- Node.js 20 或更新的 LTS 版本
- npm

## 安裝與執行

```bash
npm install
npm run dev
```

## 執行測試與建置

```bash
npm test
npm run build
```

## 第一階段包含

- 25 種魚的設定資料
- 魚竿、釣線、魚餌升級設定
- 集中式遊戲設定
- 釣魚稀有度權重與解鎖判斷基礎
- 升級費用判斷
- 離線收益計算
- 存檔建立、JSON 匯出／匯入與版本驗證
- 單元測試

## 已知限制

- 湖畔主畫面目前只是工程狀態頁。
- 尚未完成完整釣魚結算、實際魚獲處理、保底完整抽選整合、存檔遷移與小遊戲。
- 本機存檔無法防止使用者修改瀏覽器資料或系統時間。
- `localStorage` 相關函式預設使用瀏覽器環境；單元測試應傳入 mock storage，避免在 Node 環境直接呼叫。
