# 湖畔慢釣

## 簡介

湖畔慢釣是一款像素風、完全放置型的釣魚遊戲，以手機直式網頁為優先（寬 360–430px），桌機會置中顯示同一版面。頁面開著就會自動釣魚，不需要點擊；想玩時可以參與收線小遊戲，不玩也不影響進度。

## 玩法

- **自動釣魚**：頁面在前景時，每隔一段時間釣一隻魚。基礎間隔 90 秒，魚竿升到 Lv6 為 54 秒，最短 30 秒。背景分頁不會釣魚。
- **魚的去向**：普通與少見的魚自動賣成金幣。稀有、史詩、傳說進入背包，可以單隻賣出或一鍵全賣（需確認）。背包不設上限。
- **收線小遊戲（可選）**：釣到稀有以上會跳出提示。點「收線」進入張力條小遊戲：按住拉線、放開放線，讓指示器停在綠色區，把進度填滿即成功，時限 12 秒。成功的魚標記為「完美」，賣價 ×1.5。失敗或放棄照常進背包，沒有懲罰。提示 15 秒沒有動作會自動收進背包（無獎勵）。
- **升級**：魚竿、釣線、魚餌各 Lv1–6，費用逐級提高。
  - 魚竿：縮短釣魚間隔，間隔倍率 1.00 → 0.60。
  - 釣線：把普通魚的 0% → 10% 機率移給少見以上已解鎖的稀有度，越稀有的仍然越少。
  - 魚餌：提高賣魚金額，倍率 1.00 → 1.25，自動賣出與手動賣出都套用。
- **稀有度與保底**：基礎權重為普通 60、少見 25、稀有 11、史詩 3.5、傳說 0.5。連續釣不到傳說時，傳說機率會逐級提高，最高 2%。
- **圖鑑與解鎖**：共 25 種魚，第一次釣到即登錄圖鑑，未發現的顯示為「？？？」。已發現 5 種解鎖少見、10 種解鎖稀有、15 種解鎖史詩、20 種解鎖傳說。
- **離線收益**：離開後回來，最多計 4 小時，效率 50%。每一次都完整模擬抽魚（含保底與圖鑑），回來時顯示彙總視窗。
- **音樂**：設定頁可開關背景音樂、調整音量。音樂由 Web Audio 程式合成（chiptune），第一次點擊後才開始，分頁隱藏時暫停。
- **存檔管理**：設定頁可匯出 JSON、匯入存檔（會取代目前進度，需確認），或重設遊戲（需確認，無法復原）。

## 開發

需求：Node.js 20 或更新版本（CI 使用 Node 22），以及 npm。

```bash
npm install
npm run dev      # Vite 開發伺服器
npm test         # Vitest 單元測試（npm run test:watch 為監看模式）
npm run build    # tsc -b 型別檢查後執行 vite build
```

- `art-preview.html` 是開發用的像素美術預覽頁（場景、各時段、魚與圖示）。只在 `npm run dev` 時開啟 `/art-preview.html`，不會進入建置產物。
- `node src/audio/tools/render-check.mjs [輸出資料夾]` 用無頭 Chromium 離線渲染音樂與所有音效，檢查爆音與無聲，並輸出峰值、RMS 與 WAV（預設 `audio-render/`）。需要 `playwright` 套件與 Chromium，路徑預設為 `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`，可用 `CHROMIUM_PATH` 覆寫。

## 專案結構

- `src/services/`：純遊戲邏輯（釣魚、經濟、圖鑑、小遊戲、離線、存檔驗證與遷移），不依賴 React，亂數與時間皆可注入。
- `src/data/`：魚類定義、裝備數值與集中設定 `gameConfig.ts`。
- `src/types/`：共用型別與存檔版本常數。
- `src/game/`：React 與服務之間的狀態層（store、`useGame`、啟動載入、音訊單例）。
- `src/components/`：React 畫面與元件（湖畔、背包、升級、圖鑑、設定、小遊戲）。
- `src/art/`：程式繪製的像素美術（場景、魚、圖示），不依賴 React。
- `src/audio/`：Web Audio 合成的音樂與音效；`tools/` 放離線渲染檢查。
- `src/styles/`：全域樣式（`app.css`）。

## 存檔

- 儲存於瀏覽器 `localStorage`，key 為 `lake-fishing-save`。
- 自動存檔時機：每次釣到魚、每次買賣升級、頁面切到背景時。
- 目前格式為 `saveVersion: 2`。v1 存檔會自動遷移：魚 ID `fish_cultrure` 改為 `fish_xenocypris`，舊的魚獲依稀有度換成金幣或進背包，設定欄位也一併轉換。
- 讀檔失敗（JSON 壞掉或驗證不過）時，原始字串會備份到 `lake-fishing-save-corrupt-<timestamp>`（同一時間重複時加上 `-1`、`-2` 等後綴），接著開新遊戲並告知玩家。

## 已知限制

- 存檔只存在本機瀏覽器，玩家可以直接改寫 localStorage，也可以調整裝置時間。時間倒退視為 0，但向前調整仍會增加離線收益（上限 4 小時）。
- 尚未部署。CI（`.github/workflows/lake-fishing.yml`）只在 `lake-fishing/` 變更時執行 `npm ci`、`npm test`、`npm run build`，沒有部署步驟。
- 目前沒有 PWA 功能，沒有 manifest 或 Service Worker，也不能離線安裝。
